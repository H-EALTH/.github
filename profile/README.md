# H-EALTH

Software per la sanità: strumenti per le aziende sanitarie.

Progettiamo e sviluppiamo applicazioni a supporto delle attività cliniche e organizzative delle strutture sanitarie, con particolare attenzione ad affidabilità, tracciabilità e conformità alla normativa di settore.

La maggior parte dei repository di questa organizzazione è privata, perché contiene software realizzato per singole aziende sanitarie. Qui restano pubblici i file comuni e i componenti che possiamo condividere.

## Sicurezza

Per segnalare una vulnerabilità segui le indicazioni in [SECURITY.md](https://github.com/H-EALTH/.github/blob/main/SECURITY.md). Non aprire issue pubbliche.
